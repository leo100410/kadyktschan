# Prototyp: Notizbuch-Thesen

**Hypothese:** Wer die Funde einer Zeugen-Wohnung liest und eine These mit festen Feldern ausfüllt, hat das Gefühl „ich habe es verstanden“. Das gilt als bestätigt, wenn **These 2 in höchstens 3 Versuchen** gelöst wird und die Begründung **mindestens zwei passende Funde** nennt (Kalender/Brief für das Wann, Foto/Band für das Wo).

**Riskanteste Annahme:** Das Feedback „X von N Feldern stimmen“ ohne Strafe lädt zum Durchprobieren ein (These 2 hat nur 125 Kombinationen). Dann wäre es Raten statt Verstehen.

**Starten:** `prototype.html` doppelklicken (Browser genügt). Am Ende „Auswertung zeigen“ und den Text an Claude geben.

**Inhalt:** eine Wohnung, 9 Funde (4 sofort, 5 erst nach These 1), 2 Thesen, Ablenker (Nachbarzettel 1984, Kinderzeichnung 1990, Brief von 2002 mit „nächsten Herbst“, Stollen geschlossen 2001). Familie, Wohnung und Stollen sind FIKTION.

**Bewusst weggelassen:** 3D, Grafik, Ton, Lampe, Kälte, Stadtplan, Speichern.
